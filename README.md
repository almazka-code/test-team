# Тестовое задание на позицию<br>«Frontend-разработчик стажер на React»

Проект выполнен в качестве тестового задания на стажировку в компанию Antipoff Group. Проект представляет собой React приложение, в котором на главной странице отображается список карточек пользователей и по клику на каждую из них открывается страница с детальной информацией о пользователе. Чтобы увидеть этот список, пользователю необходимо зарегистрироваться или авторизоваться.

⚠️ Пожалуйста, ознакомьтесь с разделом **Важная информация для проверки проекта**.

## Функционал проекта

В приложении реализованы следующие возможности:

- регистрация и авторизация пользователя;
- валидация полей формы;
- взаимодействие с api [reqres.in](https://reqres.in) для получения данных о пользователях, а также регистрации и авторизации;
- отображение карточек пользователей виртуальной компании;
- возможность ставить лайки карточкам пользователей, которые сохраняются после перезагрузки страницы;
- подгрузка дополнительных карточек при нажатии на кнопку «Показать еще»;
- просмотр подробной информации по конкретному пользователю виртуальной компании.
